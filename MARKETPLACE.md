**Tagline:** Provision Linode (Akamai) services from PeltyCMS orders

## Linode (Akamai) provisioning for PeltyCMS

Create, suspend, unsuspend and terminate customer services on Linode (Akamai) when orders are paid or cancelled. Credentials stay in Pelty secrets; the module runs as sandboxed WASM.

### Features
- Create / suspend / unsuspend / terminate
- Password + package sync hooks
- Works with Pelty product module mapping
- MythicCloud panel download supported

### Requirements
- Reachable Linode (Akamai) API/panel
- API token or login configured in Pelty
